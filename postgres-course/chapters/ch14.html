ما هو Flat File؟What is a Flat File?

الـ Flat File هو ملف نصي بسيط يحتوي سجل واحد لكل سطر، مثل CSV أو TSV.

A Flat File is a simple text file with one record per line, such as CSV or TSV.

مثال CSV:CSV example:

id,name,email
1,Alice,alice@ex.com
2,Bob,bob@ex.com
3,Carol,carol@ex.com

مثال TSV (tab-separated):TSV example:

1	Alice	alice@ex.com
2	Bob	bob@ex.com
3	Carol	carol@ex.com

أمر COPYThe COPY Command

COPY أسرع بكثير من INSERT لأنه يتخطى جدول الـ parser ويكتب البيانات مباشرة.

COPY is much faster than INSERT — it bypasses the parser and writes data directly.

-- Import from server-side file (superuser only)
COPY customers(id, name, email)
FROM '/var/data/customers.csv'
WITH (FORMAT csv, HEADER true, DELIMITER ',');

-- Export to server-side file
COPY customers TO '/var/data/export.csv'
WITH (FORMAT csv, HEADER true);

-- Import with complex options
COPY orders FROM '/tmp/orders.csv' WITH (
  FORMAT csv,
  HEADER true,
  DELIMITER ',',
  NULL 'NULL',
  QUOTE '"',
  ESCAPE '\\',
  ENCODING 'UTF8'
);

-- From STDIN (used with psql \copy)
COPY customers FROM STDIN WITH (FORMAT csv, HEADER true);
-- then type or pipe data, end with \.

-- Export specific columns with WHERE clause
COPY (SELECT name, email FROM customers WHERE active = true)
TO '/tmp/active_users.csv'
WITH (FORMAT csv, HEADER true);
ملاحظة: Note: COPY يحتاج صلاحية superuser للوصول لملفات السيرفر. للمستخدمين العاديين، استخدم \copy في psql (ينقل من client-side). COPY requires superuser to access server files. Regular users should use \copy in psql (client-side).

\copy في psql\copy in psql

# From psql session
\copy customers FROM 'customers.csv' WITH (FORMAT csv, HEADER true);
\copy customers TO 'export.csv' WITH (FORMAT csv, HEADER true);

# From command line (one-liner)
psql -d mydb -c "\copy customers FROM 'customers.csv' CSV HEADER"

# Using pipe (import from URL or other source)
curl https://example.com/data.csv | \
  psql -d mydb -c "\copy customers FROM STDIN WITH (FORMAT csv, HEADER true)"

COPY FREEZE للأداءCOPY FREEZE for Performance

COPY FREEZE يضع الصفوف في حالة frozen مباشرة — يتجنب VACUUM FREEZE لاحقاً، مفيد جداً لتحميل كميات كبيرة دفعة واحدة.

COPY FREEZE inserts rows as frozen immediately — avoids later VACUUM FREEZE, great for bulk loads.

-- Requirements: table must be created or truncated in same transaction
BEGIN;
  TRUNCATE staging_data;  -- or CREATE TABLE
  COPY staging_data FROM '/data/big_file.csv' WITH (FORMAT csv, FREEZE);
COMMIT;

-- Bonus: maximize bulk load performance
BEGIN;
  CREATE UNLOGGED TABLE bulk_load (...);  -- no WAL
  COPY bulk_load FROM '/data/huge.csv' WITH (FORMAT csv);
  -- Index and constraints AFTER load
  CREATE INDEX ON bulk_load (id);
  ALTER TABLE bulk_load SET LOGGED;  -- enable WAL after
COMMIT;

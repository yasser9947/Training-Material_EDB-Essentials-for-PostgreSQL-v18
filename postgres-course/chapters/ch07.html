ما هو pg_catalog؟What is pg_catalog?

pg_catalog هو schema خاص يحتوي على كل ميتاداتا قاعدة البيانات — الجداول، الأعمدة، الفهارس، المستخدمين، والدوال. يُنشأ تلقائياً ودائماً جزء من search_path.

pg_catalog is a special schema containing all database metadata — tables, columns, indexes, users, and functions. Auto-created and always part of the search_path.

استعلامات مفيدةUseful Queries

-- Database sizes
SELECT datname,
       pg_size_pretty(pg_database_size(datname)) AS size
FROM pg_database
ORDER BY pg_database_size(datname) DESC;

-- Largest tables
SELECT schemaname, tablename,
       pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
FROM pg_tables
WHERE schemaname NOT IN ('pg_catalog','information_schema')
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC
LIMIT 10;

-- Active connections
SELECT pid, usename, application_name, state, query_start, query
FROM pg_stat_activity
WHERE state != 'idle';

-- Unused indexes
SELECT schemaname, relname, indexrelname
FROM pg_stat_user_indexes
WHERE idx_scan = 0;

-- Table bloat estimate
SELECT schemaname, relname,
       n_dead_tup, n_live_tup,
       ROUND(100.0 * n_dead_tup / NULLIF(n_live_tup + n_dead_tup, 0), 2) AS dead_pct
FROM pg_stat_user_tables
WHERE n_dead_tup > 1000
ORDER BY dead_pct DESC;

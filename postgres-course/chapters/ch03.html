التثبيت على Rocky Linux / RHELInstall on Rocky Linux / RHEL

# 1. Add official PostgreSQL repo
sudo dnf install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-9-x86_64/pgdg-redhat-repo-latest.noarch.rpm

# 2. Disable built-in (older) PostgreSQL module
sudo dnf -qy module disable postgresql

# 3. Install PostgreSQL 18 server + common extensions
sudo dnf install -y postgresql18-server postgresql18-contrib

# 4. Initialize the cluster with UTF-8 + password auth
sudo PGSETUP_INITDB_OPTIONS="--encoding=UTF8 --locale=en_US.UTF-8" \
     /usr/pgsql-18/bin/postgresql-18-setup initdb

# 5. Enable & start service
sudo systemctl enable --now postgresql-18

# 6. Check status
sudo systemctl status postgresql-18

# 7. Open firewall port (if remote access needed)
sudo firewall-cmd --add-service=postgresql --permanent
sudo firewall-cmd --reload

# 8. Set password for postgres DB user
sudo -u postgres psql -c "ALTER USER postgres PASSWORD 'strongpass';"

# 9. Verify
sudo -u postgres psql -c "SELECT version();"

التثبيت على Ubuntu / DebianInstall on Ubuntu / Debian

# 1. Add PostgreSQL repo
sudo sh -c 'echo "deb https://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" \
  > /etc/apt/sources.list.d/pgdg.list'

# 2. Import signing key
curl -fsSL https://www.postgresql.org/media/keys/ACCC4CF8.asc | \
  sudo gpg --dearmor -o /etc/apt/keyrings/postgresql.gpg

# 3. Update & install
sudo apt update
sudo apt install -y postgresql-18 postgresql-contrib-18

# 4. Ubuntu auto-initializes a cluster at /var/lib/postgresql/18/main
# Check clusters
pg_lsclusters

# 5. Start/stop using pg_ctlcluster or systemctl
sudo systemctl status postgresql
ملاحظة: Note: Debian/Ubuntu يستخدم أدوات مخصصة مثل pg_lsclusters و pg_createcluster — مختلفة عن RHEL/Rocky. Debian/Ubuntu uses special tools like pg_lsclusters and pg_createcluster — different from RHEL/Rocky.

Docker — الأسرع للتطويرDocker — Fastest for Dev

# One-liner: start PostgreSQL 18
docker run -d \
  --name pg18 \
  -e POSTGRES_PASSWORD=strongpass \
  -e POSTGRES_DB=myapp \
  -p 5432:5432 \
  -v pgdata:/var/lib/postgresql/data \
  postgres:18

# Connect from host
docker exec -it pg18 psql -U postgres

مستخدم postgres و الصلاحياتThe postgres User & Permissions

عند تثبيت PostgreSQL، يُنشأ مستخدم نظام تشغيل باسم postgres. هذا المستخدم:

Installing PostgreSQL creates OS user postgres. This user:

  • يملك مجلد PGDATA وكل محتوياته
  • Owns the PGDATA directory and all contents
  • يشغّل عملية السيرفر — لا يُسمح بتشغيل السيرفر كـ root لأسباب أمنية
  • Runs the server process — root is disallowed for security
  • نفس الاسم موجود أيضاً كـ superuser داخل قاعدة البيانات
  • Same name also exists as a database superuser
# Switch to postgres OS user
sudo -i -u postgres

# Now you can run Postgres commands
psql
pg_ctl status
initdb --version

# PGDATA must be owned by postgres (700 perms)
ls -la /var/lib/pgsql/18/data | head
# drwx------ 19 postgres postgres ... data

VariableالوظيفةPurposeمثالExample

PGPORTمنفذ الاتصالConnection port5432
PGUSERالمستخدم الافتراضيDefault userpostgres
PGDATABASEاسم القاعدة الافتراضيةDefault DB namemyapp
PGHOSTعنوان السيرفرServer hostlocalhost
PGPASSWORDكلمة المرور (غير آمن!)Password (insecure!)use ~/.pgpass instead
PATHيجب تضمين /usr/pgsql-18/binMust include /usr/pgsql-18/bin—

أضف للـ ~/.bashrc أو ~/.profile:

Add to ~/.bashrc or ~/.profile:

export PGDATA=/var/lib/pgsql/18/data
export PATH=/usr/pgsql-18/bin:$PATH
export PGPORT=5432

# Apply changes
source ~/.bashrc
مهم للأمان: Security tip: لا تستخدم PGPASSWORD في البيئة — يظهر في ps. استخدم ملف ~/.pgpass بصلاحيات 600. Never use PGPASSWORD — it shows in ps. Use ~/.pgpass with 600 perms.

ملف .pgpassThe .pgpass File

# Format: hostname:port:database:username:password
echo "localhost:5432:myapp:myuser:mypassword" > ~/.pgpass
chmod 600 ~/.pgpass

# Now psql auto-reads password — no prompt
psql -h localhost -U myuser -d myapp

# Wildcards are allowed:
# *:*:*:postgres:adminpass

تثبيت على Rocky LinuxInstall on Rocky Linux

الخطوات الأساسية لتثبيت PostgreSQL 18 على Rocky Linux:

Basic steps to install PostgreSQL 18 on Rocky Linux:

# 1. Add PostgreSQL official repository
sudo dnf install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-9-x86_64/pgdg-redhat-repo-latest.noarch.rpm

# 2. Disable built-in PostgreSQL module
sudo dnf -qy module disable postgresql

# 3. Install PostgreSQL 18
sudo dnf install -y postgresql18-server postgresql18-contrib

# 4. Initialize database cluster
sudo /usr/pgsql-18/bin/postgresql-18-setup initdb

# 5. Enable and start the service
sudo systemctl enable postgresql-18
sudo systemctl start postgresql-18

# 6. Verify installation
sudo -u postgres psql -c "SELECT version();"
تنبيه:Warning: مستخدم postgres يُنشأ تلقائياً في نظام التشغيل ويمتلك مجلد البيانات. لا تقم بتشغيل السيرفر كـ root! The postgres OS user is auto-created and owns the data directory. Never run the server as root!

متغيرات البيئةEnvironment Variables

المتغيرVariableالوظيفةPurpose
PGDATAمسار مجلد البياناتData directory path
PGPORTرقم منفذ السيرفر (افتراضي 5432)Server port number (default 5432)
PGUSERالمستخدم الافتراضي للاتصالDefault connection user
PGDATABASEاسم قاعدة البيانات الافتراضيةDefault database name
PGHOSTعنوان السيرفرServer hostname/IP
PATHيجب أن يحتوي مسار /usr/pgsql-18/binMust include /usr/pgsql-18/bin
 
# Add to ~/.bashrc (for postgres user)
export PGDATA=/var/lib/pgsql/18/data
export PATH=/usr/pgsql-18/bin:$PATH
export PGPORT=5432

# Apply changes
source ~/.bashrc

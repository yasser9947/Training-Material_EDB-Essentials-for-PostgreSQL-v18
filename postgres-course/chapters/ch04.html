طرق الاتصالConnection Methods

# 1. Local as postgres OS user (peer auth)
sudo -u postgres psql

# 2. Specify database only
psql -d mydb

# 3. Full connection parameters
psql -U alice -h db.example.com -p 5432 -d sales

# 4. Connection URI (modern way)
psql "postgresql://alice:secret@db.example.com:5432/sales"
psql "postgresql://alice@db.example.com/sales?sslmode=require"

# 5. Run single query and exit
psql -d mydb -c "SELECT COUNT(*) FROM users;"

# 6. Run SQL file
psql -d mydb -f script.sql

# 7. Run from STDIN
echo "SELECT NOW();" | psql -d mydb

# 8. Quiet mode (for scripts)
psql -d mydb -At -c "SELECT count(*) FROM orders" # -A unaligned, -t tuples-only

# 9. Expanded output for wide tables
psql -d mydb -x -c "SELECT * FROM users LIMIT 1;"

جلسة psql احترافيةPro psql Session

-- Enter psql and explore
\c sales                         -- switch to sales DB
\timing on                       -- measure query time

-- List tables and check sizes
\dt+

-- Examine customers table
\d+ customers

-- Find a user quickly
SELECT * FROM customers WHERE email = 'alice@example.com' \gx
-- \gx runs query and shows expanded output

-- Create a quick report file
\o /tmp/top_customers.csv
COPY (
  SELECT c.name, SUM(o.total) AS total_spent
  FROM customers c JOIN orders o ON o.customer_id = c.id
  GROUP BY c.name ORDER BY total_spent DESC LIMIT 20
) TO STDOUT WITH CSV HEADER;
\o

-- Monitor active queries in real-time
SELECT pid, state, query FROM pg_stat_activity WHERE state='active';
\watch 5   -- refreshes every 5 seconds (Ctrl+C to stop)

-- Quit
\q

متغيرات psql و الأوامر الشرطيةVariables & Conditional Commands

-- Set a variable
\set myuser 'alice'
\set threshold 100

-- Use in queries (prefix with :)
SELECT * FROM customers WHERE name = :'myuser';
SELECT * FROM orders WHERE total > :threshold;

-- Conditional execution (useful in scripts)
SELECT COUNT(*) FROM users \gset
-- Sets variable :count with the result
\if :count > 0
  \echo 'Users exist!'
\else
  \echo 'No users yet.'
\endif

-- Exit on error (strict mode for scripts)
\set ON_ERROR_STOP on
\set AUTOCOMMIT off

ملف psqlrc — تخصيص دائمpsqlrc — Permanent Customization

أنشئ ~/.psqlrc ليُنفذ تلقائياً عند كل جلسة:

Create ~/.psqlrc — auto-runs every session:

\set QUIET 1                           -- silence startup
\pset null '¤'                         -- visual NULL
\pset linestyle unicode                -- pretty borders
\pset border 2
\timing on                             -- always show timing
\set HISTFILE ~/.psql_history- :DBNAME -- per-DB history
\set HISTSIZE 2000
\set COMP_KEYWORD_CASE upper
\set PROMPT1 '%[%033[1;33m%]%n@%/%[%033[0m%]%R%#%x '
\set PROMPT2 '... %# '
\set ON_ERROR_ROLLBACK interactive
\unset QUIET

-- Custom aliases
\set version 'SELECT version();'
\set conninfo 'SELECT usename, client_addr, state FROM pg_stat_activity;'
\set uptime 'SELECT NOW() - pg_postmaster_start_time() AS uptime;'
بعد هذا، تستطيع كتابة :version بدلاً من الاستعلام الكامل.
Now you can just type :version instead of the full query.

ما هو psql؟What is psql?

psql هو واجهة سطر الأوامر الرسمية للتعامل مع PostgreSQL. يمكنك من تنفيذ استعلامات SQL، إدارة قواعد البيانات، وتشغيل ملفات SQL.

psql is the official command-line interface for PostgreSQL. It lets you execute SQL queries, manage databases, and run SQL scripts.

الاتصال بقاعدة البياناتConnecting to Database

# Connect as postgres user to default database
sudo -u postgres psql

# Connect to a specific database
psql -d mydb

# Connect with user, host, and port
psql -U myuser -h localhost -p 5432 -d mydb

# Connect using connection string (URI)
psql "postgresql://user:pass@host:5432/dbname"

# Run a single query and exit
psql -d mydb -c "SELECT COUNT(*) FROM users;"

# Execute SQL file
psql -d mydb -f script.sql

جلسة عملية كاملةComplete Practical Session

مثال لجلسة psql كاملة — استكشاف قاعدة بيانات:

A complete psql session — exploring a database:

-- Connect and explore
\c edbstore

-- List tables in current database
\dt

-- Describe 'customers' table
\d customers

-- Enable query timing
\timing

-- Run a query
SELECT customerid, firstname, lastname
FROM customers
LIMIT 5;

-- Switch to expanded display for wide rows
\x

-- Save query results to a file
\o output.txt
SELECT * FROM orders WHERE orderdate > '2024-01-01';
\o

-- Quit
\q

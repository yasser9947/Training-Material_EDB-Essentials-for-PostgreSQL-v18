القسم ١Section 1

الملخص المعماريArchitectural Summary

الفكرة الأساسية: Key Concept:

PostgreSQL يستخدم عمليات (Processes) وليس خيوط (Threads). عملية الـ Postmaster تعمل كـمشرف يدير كل العمليات الأخرى.

PostgreSQL uses processes, not threads. The Postmaster process acts as a supervisor managing all others.

القسم ٣Section 3

معالجة الاستعلامQuery Processing

عندما ترسل استعلام إلى PostgreSQL، يمر بعدة مراحل:

When you send a query to PostgreSQL, it goes through several stages:

1
Parser (المحلل)Parser
يتحقق من صحة بنية الاستعلام (syntax)
Validates query syntax
2
Rewriter (المعيد)Rewriter
يطبق قواعد الـ Views والـ Rules
Applies view and rule transformations
3
Planner/Optimizer (المخطط)Planner/Optimizer
يختار أفضل خطة تنفيذ بناءً على الإحصائيات
Picks optimal execution plan using statistics
4
Executor (المنفذ)Executor
ينفذ الخطة ويعيد النتائج
Executes the plan and returns results
القسم ٤Section 4

هيكلة مجلد البياناتData Directory Layout

مجلد PGDATA يحتوي على كل ملفات قاعدة البيانات:

The PGDATA directory contains all database files:

$PGDATA/
├── base/              # Per-database data files
│   └── <oid>/         # One directory per database
├── global/            # Cluster-wide tables (pg_database, etc.)
├── pg_wal/            # Write-Ahead Log files
├── pg_xact/           # Transaction commit status
├── pg_multixact/      # Multi-transaction status
├── pg_stat/           # Statistics subsystem
├── pg_tblspc/         # Symbolic links to tablespaces
├── postgresql.conf    # Main configuration file
├── pg_hba.conf        # Host-based authentication
├── pg_ident.conf      # Identity mapping
└── PG_VERSION         # Version number

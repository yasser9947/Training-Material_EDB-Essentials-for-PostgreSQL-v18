الذاكرة — القيم المهمةMemory — The Key Settings

shared_buffers

restart

ذاكرة مشتركة لـ page cache. توصية: 25% من RAM (لكن لا تزيد عن 8-16 GB حتى مع RAM كبير).

Shared page cache memory. Recommended: 25% of RAM (but cap at 8-16 GB even with large RAM).

Default: 128MB  ·  Production: 2GB – 16GB

work_mem

reload

ذاكرة لكل sort/hash/group لكل backend. تعددت في استعلام واحد! استعلام بـ 3 sorts = 3 × work_mem.

Memory per sort/hash/group per backend. Multiplies within one query! Query with 3 sorts = 3 × work_mem.

Default: 4MB  ·  Production: 16-64MB

maintenance_work_mem

reload

لـ VACUUM، CREATE INDEX، ALTER TABLE. يمكن أن يكون كبيراً — عملية واحدة فقط.

For VACUUM, CREATE INDEX, ALTER TABLE. Can be large — only one operation at a time.

Default: 64MB  ·  Production: 512MB – 2GB

effective_cache_size

reload

تقدير للـ planner (لا يحجز ذاكرة). كم من الـ cache متاح؟ توصية: 50-75% من RAM.

Hint for the planner (not actual allocation). Recommendation: 50-75% of RAM.

Default: 4GB  ·  Production: 50-75% of RAM

max_connections

restart

عدد الاتصالات المتزامنة. لا تبالغ! كل اتصال = عملية. استخدم PgBouncer بدلاً من رفع الرقم.

Concurrent connections. Don't overdo it! Each connection = one process. Use PgBouncer instead of increasing.

Default: 100  ·  Production: 100-300 (use pooler!)

WAL والنسخ الاحتياطيWAL & Backup Settings

# WAL level determines what's logged
wal_level = replica          # minimal | replica | logical
# minimal = only crash recovery
# replica = + physical replication and PITR
# logical = + logical replication (pub/sub)

# Archive for PITR
archive_mode = on
archive_command = 'test ! -f /archive/%f && cp %p /archive/%f'

# Checkpoint tuning
checkpoint_timeout = 15min   # default 5min — longer reduces I/O
max_wal_size = 4GB           # soft limit before forcing checkpoint
min_wal_size = 1GB           # keep this many for reuse
checkpoint_completion_target = 0.9  # spread I/O over 90% of timeout

# WAL writer
wal_writer_delay = 200ms     # how often to flush WAL
synchronous_commit = on      # off = faster but risk data loss on crash
حيلة أداء: Performance trick: synchronous_commit = off يجعل COMMIT أسرع بكثير، لكن قد تفقد آخر ~200ms من التغييرات في حال crash. مناسب لبعض الأحمال (analytics) وليس للأخرى (payments). synchronous_commit = off makes COMMIT much faster but risks losing last ~200ms on crash. OK for some workloads (analytics), not others (payments).

Logging — التسجيل الفعّالLogging — Effective Logs

logging_collector = on
log_directory = 'log'
log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log'
log_rotation_age = 1d
log_rotation_size = 100MB

# What to log
log_line_prefix = '%t [%p]: user=%u,db=%d,app=%a,client=%h '
log_statement = 'ddl'            # none | ddl | mod | all
log_duration = off
log_min_duration_statement = 1000   # log queries >1s
log_checkpoints = on
log_connections = on
log_disconnections = on
log_lock_waits = on
log_temp_files = 0               # log any temp file creation
log_autovacuum_min_duration = 0  # log all autovacuum runs

# Error log levels
log_min_error_statement = error
client_min_messages = warning

نصيحة: log_min_duration_statement = 1000 يسجل فقط الاستعلامات البطيئة. مفيد جداً لاستكشاف الأخطاء دون ضغط هائل على الـ log.

Tip: log_min_duration_statement = 1000 logs only slow queries — great for troubleshooting without log overload.

SET vs ALTER SYSTEM vs ALTER DATABASE/ROLESET vs ALTER SYSTEM vs ALTER DATABASE/ROLE

-- View current value
SHOW work_mem;

-- View all with details
SELECT name, setting, unit, context, pending_restart
FROM pg_settings
WHERE name LIKE '%wal%';

-- Change for CURRENT SESSION only
SET work_mem = '64MB';

-- Change for CURRENT TRANSACTION only
BEGIN;
  SET LOCAL work_mem = '256MB';  -- reverts after COMMIT
  -- heavy query here
COMMIT;

-- Change GLOBALLY (persists, writes to postgresql.auto.conf)
ALTER SYSTEM SET shared_buffers = '2GB';
SELECT pg_reload_conf();  -- if reload-able param
-- ... or restart if postmaster-level

-- Reset to default
ALTER SYSTEM RESET shared_buffers;
ALTER SYSTEM RESET ALL;

-- Per-database default
ALTER DATABASE sales SET work_mem = '128MB';

-- Per-role default (applies whenever alice connects)
ALTER ROLE alice SET search_path TO sales, public;

-- Check what requires restart
SELECT name, setting FROM pg_settings WHERE pending_restart;

تنظيم الإعدادات بـ includesOrganizing with Includes

لملف postgresql.conf طويل، قسّمه إلى ملفات صغيرة واستخدم include:

For a long postgresql.conf, split into smaller files using include:

# In postgresql.conf:
include = 'conf.d/memory.conf'
include_dir = 'conf.d'               # all .conf files in dir
include_if_exists = 'local.conf'     # silent if missing

# conf.d/memory.conf:
shared_buffers = 2GB
work_mem = 32MB

# conf.d/logging.conf:
logging_collector = on
log_filename = 'postgresql-%a.log'

عرض وتغيير الباراميترزViewing & Changing Parameters

-- View a single parameter
SHOW shared_buffers;

-- View all parameters
SHOW ALL;

-- View via system catalog (more details)
SELECT name, setting, unit, context, short_desc
FROM pg_settings
WHERE name LIKE 'wal%';

-- Change parameter at session level
SET work_mem = '16MB';

-- Change at cluster level (persistent)
ALTER SYSTEM SET shared_buffers = '2GB';

-- Reload to apply without restart
SELECT pg_reload_conf();

-- Check if restart is needed
SELECT name, setting, pending_restart
FROM pg_settings
WHERE pending_restart = true;
تنبيه: Warning: بعض الباراميترز (مثل shared_buffers) تتطلب إعادة تشغيل السيرفر لتفعيل التغيير. Some parameters (like shared_buffers) require server restart to take effect.

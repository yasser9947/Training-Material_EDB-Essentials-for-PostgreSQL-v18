ملف pg_hba.confThe pg_hba.conf File

HBA = Host-Based Authentication. هذا الملف يحدد من يستطيع الاتصال، ومن أي IP، وكيف يصادق.

HBA = Host-Based Authentication. This file defines who can connect, from which IPs, and how they authenticate.

Row Level Security (RLS)Row Level Security

الـ RLS يسمح بحصر الوصول للصفوف حسب هوية المستخدم — بحيث يرى كل مستخدم بياناته فقط.

RLS restricts row access based on user identity — each user sees only their own data.

-- Enable RLS on a table
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;

-- Create policy: users see only their own orders
CREATE POLICY orders_own_policy ON orders
  FOR ALL
  USING (customer_id = current_setting('app.current_user')::int);

-- Create policy for admins: see all
CREATE POLICY orders_admin_policy ON orders
  FOR ALL
  TO admin_role
  USING (true);

-- Test: set app user and query
SET app.current_user = '42';
SELECT * FROM orders; -- only sees customer_id = 42

-- Disable RLS (careful!)
ALTER TABLE orders DISABLE ROW LEVEL SECURITY;

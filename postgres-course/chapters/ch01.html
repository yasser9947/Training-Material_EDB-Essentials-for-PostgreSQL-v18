القسم ١Section 1

ما هو PostgreSQL؟ What is PostgreSQL?

PostgreSQL هو نظام إدارة قواعد بيانات علائقية (ORDBMS) مفتوح المصدر، يعتبر الأكثر تقدماً في العالم. يتميز بالموثوقية والأداء العالي ودعم واسع للمعايير، ويستخدم من قبل الآلاف من الشركات حول العالم.

PostgreSQL is the world's most advanced open-source object-relational database management system (ORDBMS). Known for reliability, performance, and standards compliance, it is used by thousands of companies worldwide.

نقطة مهمة: Important: PostgreSQL يستخدم العمليات (Processes) وليس الخيوط (Threads) — كل اتصال جديد ينشئ عملية مستقلة. هذا يعطي الاستقرار لكنه يستهلك ذاكرة أكثر. PostgreSQL uses processes, not threads — each new connection spawns its own process. This gives stability but uses more memory.

القسم ٦Section 6

مصطلحات PostgreSQL PostgreSQL Terminology

PostgreSQL يستخدم بعض المصطلحات المختلفة عن المصطلحات الصناعية الشائعة

PostgreSQL uses some terms that differ from common industry terminology

المصطلح الصناعي Industry Term مصطلح PostgreSQL Postgres Term
Table / Index Relation
Row Tuple
Column Attribute
Data Block Page (on disk)
Page Buffer (in memory)

لماذا المصطلحات مختلفة؟ Why Different Terms?

PostgreSQL جاء من عالم الأكاديميا وقواعد البيانات الكائنية (Object-Relational). المصطلحات مثل Tuple و Relation من نظرية قواعد البيانات العلائقية الرياضية.

PostgreSQL comes from academia and object-relational database theory. Terms like Tuple and Relation come from the mathematical theory of relational databases.

مثال عملي: أول اتصال Practical Example: First Connection

بعد تثبيت PostgreSQL، يمكنك الاتصال به وعرض معلومات الإصدار:

Once PostgreSQL is installed, you can connect and view version info: 

# Connect to PostgreSQL as postgres user
sudo -u postgres psql

# Inside psql:
postgres=# SELECT version();
postgres=# \l          -- list databases
postgres=# \q          -- quit

إنشاء كلاستر جديدCreating a Cluster

استخدم initdb لإنشاء كلاستر جديد:

Use initdb to create a new cluster:

# Create a new cluster at /var/lib/pgsql/18/edbdata
initdb -D /var/lib/pgsql/18/edbdata \
       -U postgres \
       --encoding=UTF8 \
       --locale=en_US.UTF-8

# With password auth enabled
initdb -D /var/lib/pgsql/18/edbdata \
       -U postgres \
       --pwprompt \
       --auth-host=md5

إدارة السيرفر عبر pg_ctlManaging Server via pg_ctl

# Set PGDATA environment variable first
export PGDATA=/var/lib/pgsql/18/edbdata

# Start the server
pg_ctl start

# Check status
pg_ctl status

# Reload configuration (no restart needed)
pg_ctl reload

# Restart the server
pg_ctl restart

# Stop (smart = wait for clients, fast = rollback, immediate = crash)
pg_ctl stop -m smart
pg_ctl stop -m fast
pg_ctl stop -m immediate

fast (سريع) — افتراضي

fast (default)

يلغي العمليات الجارية

Aborts in-flight transactions

immediate (فوري)

immediate

Abrupt stop — needs recovery

لماذا النسخ المتماثل؟Why Replication?

الـ Replication هو نسخ البيانات والتغييرات إلى مكان ثانوي لضمان سلامة وتوافر البيانات.

Replication copies data and changes to a secondary location for safety and availability.

أنواع النسخ المتماثلReplication Types

Synchronous (متزامن)Synchronous

الـ Primary ينتظر تأكيد الـ Replica قبل COMMIT.

Primary waits for Replica ACK before COMMIT.

✓ صفر فقدان للبيانات
✓ Zero data loss
✗ أبطأ
✗ Slower

Asynchronous (غير متزامن)Asynchronous

الـ Primary يعمل COMMIT فوراً، الـ Replica يتبع لاحقاً.

Primary commits immediately, Replica follows later.

✓ أسرع
✓ Faster
✗ احتمال فقدان بيانات صغير
✗ Small data loss possible

StreamingStreaming

نسخ WAL في الوقت الفعلي — نسخة مطابقة تماماً (physical).

Real-time WAL shipping — identical physical copy.

LogicalLogical

نسخ على مستوى الجدول — يمكن انتقاء جداول معينة.

Per-table replication — selective tables only.

إعداد Streaming ReplicationSetup Streaming Replication

# ===== On PRIMARY =====

# 1. Create replication user
CREATE USER replicator REPLICATION LOGIN PASSWORD 'repl_pass';

# 2. Configure postgresql.conf
# wal_level = replica
# max_wal_senders = 10
# wal_keep_size = 1GB   # or use replication slots
# hot_standby = on

# 3. Allow replica connection in pg_hba.conf
host replication replicator 10.0.0.2/32 scram-sha-256

# 4. Restart primary
pg_ctl restart

# ===== On REPLICA =====

# 5. Stop and remove old data
pg_ctl stop
rm -rf /var/lib/pgsql/18/data/*

# 6. Base backup from primary
pg_basebackup -h primary.host -U replicator \
              -D /var/lib/pgsql/18/data \
              -P -R -X stream -C -S replica_slot1

# 7. The -R flag creates standby.signal & postgresql.auto.conf with:
# primary_conninfo = 'host=primary.host user=replicator password=...'

# 8. Start replica
pg_ctl start

# ===== Verification =====
# On primary:
SELECT * FROM pg_stat_replication;

# On replica:
SELECT pg_is_in_recovery();   -- true
SELECT pg_last_wal_receive_lsn(), pg_last_wal_replay_lsn();

Logical ReplicationLogical Replication

-- ===== PUBLISHER (source) =====
-- wal_level must be 'logical' in postgresql.conf

CREATE PUBLICATION my_pub FOR TABLE customers, orders;
-- Or all tables
CREATE PUBLICATION all_pub FOR ALL TABLES;

-- ===== SUBSCRIBER (destination) =====
-- First: create matching table structure
CREATE TABLE customers (...);
CREATE TABLE orders (...);

-- Create subscription (starts replication)
CREATE SUBSCRIPTION my_sub
  CONNECTION 'host=pub.host dbname=mydb user=repl password=pass'
  PUBLICATION my_pub;

-- Check status
SELECT * FROM pg_stat_subscription;

-- Refresh after adding new tables to publication
ALTER SUBSCRIPTION my_sub REFRESH PUBLICATION;

إدارة المستخدمين والأدوارManaging Users & Roles

فكرة مهمة: Key idea: في PostgreSQL، User هو Role له صلاحية LOGIN. الأدوار بدون LOGIN تعمل كمجموعات. In PostgreSQL, a User is a Role with LOGIN privilege. Roles without LOGIN act as groups. 
-- Create a user (role with LOGIN)
CREATE USER alice WITH PASSWORD 'secret123';

-- Create a group role (no login)
CREATE ROLE developers;

-- Add user to group
GRANT developers TO alice;

-- Grant privileges to a role
GRANT SELECT, INSERT ON ALL TABLES IN SCHEMA public TO developers;

-- Create superuser
CREATE USER admin WITH SUPERUSER PASSWORD 'admin_pass';

-- Change password
ALTER USER alice WITH PASSWORD 'newpass';

-- Set connection limit
ALTER ROLE alice CONNECTION LIMIT 5;

-- Drop user (must remove ownership first)
REASSIGN OWNED BY alice TO postgres;
DROP OWNED BY alice;
DROP USER alice;

TablespacesTablespaces

الـ Tablespace هو مسار على القرص تخزن فيه قواعد البيانات. يسمح لك بتوزيع البيانات على أقراص مختلفة لتحسين الأداء.

A Tablespace is a disk location where databases store files. Useful for distributing data across disks for performance.

-- Create tablespace (directory must exist and be owned by postgres)
CREATE TABLESPACE fast_ssd
  LOCATION '/mnt/ssd/pgdata';

-- Create table in a tablespace
CREATE TABLE large_table (id serial, data text)
  TABLESPACE fast_ssd;

-- Move existing table
ALTER TABLE large_table SET TABLESPACE fast_ssd;

-- Set default tablespace for current session
SET default_tablespace = 'fast_ssd';

-- List tablespaces
SELECT spcname, pg_tablespace_location(oid) FROM pg_tablespace;

الـ Schemas و search_pathSchemas & search_path

-- Create schema
CREATE SCHEMA sales;
CREATE SCHEMA marketing AUTHORIZATION alice;

-- Create tables in specific schemas
CREATE TABLE sales.orders (...);
CREATE TABLE marketing.campaigns (...);

-- Qualified name access
SELECT * FROM sales.orders;

-- View current search_path
SHOW search_path;

-- Change search_path (in order of search)
SET search_path TO sales, public;

-- Set default for database
ALTER DATABASE mydb SET search_path TO sales, public;

-- Drop schema (CASCADE removes all objects!)
DROP SCHEMA marketing CASCADE;

صلاحيات الوصول (GRANT/REVOKE)Access Control

-- Grant object-level privileges
GRANT SELECT, INSERT, UPDATE ON customers TO alice;
GRANT ALL PRIVILEGES ON orders TO developers;

-- Grant on all tables in schema
GRANT SELECT ON ALL TABLES IN SCHEMA sales TO analyst;

-- Default privileges for future tables
ALTER DEFAULT PRIVILEGES IN SCHEMA sales
  GRANT SELECT ON TABLES TO analyst;

-- Revoke privileges
REVOKE INSERT ON customers FROM alice;

-- Grant USAGE on schema (needed before table access)
GRANT USAGE ON SCHEMA sales TO analyst;

-- Check current privileges
\dp customers
